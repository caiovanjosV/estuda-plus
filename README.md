# Estuda+ — Front-end

Protótipo front-end da aplicação web Estuda+, desenvolvido para apresentação acadêmica.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Como executar
1. Extraia a pasta.
2. Abra `index.html` no navegador.
3. Para uma experiência melhor, abra a pasta no VS Code e use o Live Server.

## Observação
Esta versão é um protótipo front-end. Os dados são manipulados em memória no JavaScript e ainda não estão conectados ao Node.js/MySQL.
